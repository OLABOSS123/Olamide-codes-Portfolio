## ✨ Features

### 🎯 Responsive Design

The website is designed to work across:

* Desktop
* Laptop
* Tablet
* Mobile devices

Responsive breakpoints are implemented to maintain a consistent layout across different screen sizes.

---

### ⌨️ Typing Animation

The hero section includes a dynamic typing animation that cycles through different professional roles:

```text
Full Stack Developer
Frontend Developer
Web Developer
Software Developer
```

The animation is implemented using vanilla JavaScript.

---

### 🧭 Interactive Sidebar Navigation

The portfolio includes a sidebar navigation system with an active navigation state.

The active link is highlighted using:

* Accent color
* Animated indicator
* Glow effect
* Hover transitions

---

### 🗂️ Project Filtering

Projects can be filtered by category.

Available categories include:

```text
All
Web
Frontend
Backend
UI/UX
```

The filtering system is powered by JavaScript.

---

### 📄 Downloadable CV

The website includes a **Download CV** feature.

When the user clicks the button, JavaScript dynamically generates the CV and opens the browser's print dialog, allowing the user to save it as a PDF.

The CV follows the same dark futuristic visual style as the portfolio.

---

The website includes several visual effects:

* Hover animations
* RGB glow effects
* Smooth transitions
* Animated navigation indicators
* Interactive project cards
* Technology icon animations
* Button hover effects
